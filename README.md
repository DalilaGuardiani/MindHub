# MindHub

MindHub è un progetto universitario realizzato come web app di giochi.  
L’applicazione permette agli utenti di registrarsi, effettuare il login, giocare, visualizzare il proprio profilo e consultare i punteggi nella leaderboard.

## Struttura del progetto

Il progetto è diviso in due parti principali:

- **frontend**: pagine HTML, stile CSS, logica JavaScript dei giochi e chiamate al backend;
- **backend**: server Node.js/Express, API REST e collegamento al database Supabase.

## Funzionalità principali

- Registrazione e login utente.
- Profilo personale con username, email, avatar e statistiche di gioco.
- Giochi disponibili: Memory, Sudoku, Tic Tac Toe e Snake.
- Salvataggio dei punteggi per gli utenti registrati.
- Leaderboard generale e filtrata per gioco.
- Modalità ospite: permette di giocare senza account, senza salvare i punteggi.

## Tecnologie utilizzate

- HTML
- CSS
- JavaScript
- Bootstrap
- Node.js
- Express
- Supabase

## Avvio del progetto

Per avviare il backend:

```bash
cd backend
npm install
npm start
```

Poi aprire il sito dal browser all’indirizzo:

```txt
http://localhost:3000
```
